This package includes a community-modified NVIDIA neural-rendering DLL
(ShortFuse's universal 310.8.SF-v2 build). The modification removed its
embedded Authenticode signature, so the file is unsigned. The ReShade proxy
and RenoDX add-on are unsigned. These facts are separate from malware
detection; a matching hash is not a malware scan or proof of legitimacy.

The runtime policy enables neural rendering on every detected NVIDIA RTX GPU
(GeForce RTX 20 through 50 and RTX-branded workstation/laptop parts). NVIDIA's
official DLSS 5 launch support is RTX 50-only, with RTX 40 announced for
later; support for anything else here is an unofficial community
modification, verified in this project on an RTX 5090 and an RTX 4080 SUPER.
DLAA is the default native-resolution carrier, so spatial DLSS upscaling
remains off until the user explicitly selects it.

If the experimental path misbehaves, choose Advanced > Restart in DLSS SR safe
mode, or launch `DLSSVideoPlayer.exe --safe-mode`. Safe mode disables the
experimental add-on without claiming that normal mode successfully evaluated a
neural workload.
