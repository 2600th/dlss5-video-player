Scope: the project's single landing page at `site/src/index.html`, deployed to
GitHub Pages. Visitor mode: Persuade.

Audience: an RTX owner deciding whether to download 308 MB of unsigned community
software. The job: find out whether the render actually looks better, and by how
much. The action: download the current build. The proof: one frame captured
twice with only Neural Rendering switched, plus the 22-second demo and the
published verification numbers. Constraints: the community-project and
unsigned-runtime notices are binding; the project's voice is measured and
numeric, never promotional.

## Direction contract

THESIS: an image-quality breakdown, not a product page. It refuses the glowing-GPU
hero and the row of feature cards.

OWN-WORLD: true black under fine grain. One ink, flag orange, carried at real
scale and never as glow. Condensed grotesk caps for labels; mono only where a
value was measured. Hairline ticks, no containers.

STORY: the visitor moves a seam across one frame, sees the difference under their
own hand, believes it because they caused it, and downloads the build.

FIRST VIEWPORT: the Godfather still near full-bleed, split by a vertical
flag-orange seam with a grip. ORIGINAL and NEURAL track the seam as tick-labels
at the frame's top edge. A dense provenance band - frame, timestamp, resolution,
cache key - packs the lower left against an otherwise bare frame. Wordmark
top-left. Headline and the orange download button, carrying version and size,
sit over the frame's left third.

FORM: analysis breakdown; candidate 3 of 7; seed d40c0a7a.

RAISE (cutting-bench select rail, competitive): state is a mark, not a hue.
RAISE (shibuya obi band, competitive): density collision - one band packed with
real provenance against a bare frame.
RAISE (neon circuit, declined): the ink is one continuous element, never
scattered highlights.
RAISE (ascii live render, declined): the technique is really built - real pixels
at real resolution, no CSS approximation of the evidence.
RAISE (coptic binding, declined): nothing decorative; every rule and tick is
load-bearing.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Memorable moment

The seam sweeps once on entry, exponential ease-out, and stops off-centre so the
split is visible before the visitor touches it. Suppressed under
`prefers-reduced-motion`.

## Unresolved

GA4 measurement ID, supplied by the maintainer at the end and injected at build
time from a repository variable.
