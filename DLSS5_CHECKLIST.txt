DLSS VIDEO PLAYER V11 - QUICK DLSS 5 CHECK
==========================================

1) Install ReShade with add-on support for DLSSVideoPlayer.exe (DirectX 10/11/12).
2) Get the experimental DLSS 5 runtime and renodx-dlss5.addon64 from:
   https://app.mediafire.com/folder/sa9zioqbixj7e
3) Put the matching runtime files beside DLSSVideoPlayer.exe:
   nvngx_dlssnr.dll
   renodx-dlss5.addon64
   matching nvngx_dlss.dll if the package provides one
   ReShade proxy/config files
   any matching sl.*.dll modules required by that package
4) First-run note: press Home and verify the RenoDX add-on is enabled under ReShade > Add-ons.
5) Run prepare_dlss5_test.bat.
6) Open a video. Auto quality + original aspect ratio (Fit) are the defaults.
7) Press 3 / click MV: colors should react to camera/object motion.
8) Press 4 / click Depth: estimated depth should be non-flat.
9) Press 5 / click Mask: mostly black, brighter around uncertain/disoccluded motion.
10) RenoDX should see CreateFeature > 0 and increasing EvaluateFeature_C activity.
11) F6 forces another NGX create/re-hook.
12) Ctrl+Alt+Space pauses/resumes even while ReShade captures normal input.
13) Ctrl+Alt+C opens Image Adjustments while ReShade is open.
14) While paused, the player keeps presenting the frozen frame so the ReShade UI remains responsive.

Base runtime:
DLSSVideoPlayer.exe
nvngx_dlss.dll
ffmpeg.exe
ffprobe.exe

Internal NGX contract:
Color  = R16G16B16A16_FLOAT, linear, render resolution
Motion = R16G16_FLOAT, current -> previous, input-pixel units
Depth  = one R32_TYPELESS resource; D32_FLOAT DSV + R32_FLOAT SRV; same resource passed to NGX
Bias   = R8_UNORM temporal uncertainty mask
Output = R16G16B16A16_FLOAT UAV, target resolution
Jitter = Halton
Reset  = cut / seek / discontinuity / drop / recreate
Eval   = NVSDK_NGX_D3D12_EvaluateFeature_C with legacy fallback only if needed

Normal encoded video does not contain the game's original Z-buffer or object motion vectors.
The player reconstructs those temporal guides from decoded frames.
